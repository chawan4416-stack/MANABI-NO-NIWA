# まなびのにわ 🌱

4歳児向けの個人利用iPad学習PWA。絵本の世界で、ひらがな・数・ちえを冒険と自由遊びにつなげます。

## Ver.0.1（開発用）

- ホーム画面：ぼうけん／じゆうあそび／かぞく
- 冒険：『り』探し→りんご3個→道→お店→なぞり書き→達成（6場面）
- 自由遊び：果物のお店屋さん、個数を選んで注文（冒険未達成でも利用可能）
- かぞく：遊び方ガイドとA4復習プリント（ブラウザの印刷機能）
- PWA：ホーム画面追加・基本ファイルのオフラインキャッシュ
- 完了フラグのみ端末の localStorage に保存。遊んだ履歴、氏名、ログイン、分析なし。

## 現状の制限

- これは**操作・学習フロー確認用の試作版**。正式採用された水彩絵本イラストは未組み込みで、絵文字とCSSの仮素材を使用。
- なぞり書きは指で線を引けるが、字形の自動判定はまだない。
- 『おてがみ』『めいろ』など自由遊びの追加メニューは準備中。
- 端末内の保存はSafariのサイトデータ消去で失われる可能性がある。Supabase接続とバックアップは後工程。
- 初期公開前にiPad Safariでの実機動作・印刷・オフラインを確認する。

## 開発と公開

- 開発ブランチ：`dev`
- 公開候補ブランチ：`main`（承認後に反映）
- GitHub Pagesを有効にする場合、リポジトリの Settings → Pages で設定。
- このリポジトリはCPLとは無関係であり、個人情報やSupabaseの秘密鍵を配置しない。
